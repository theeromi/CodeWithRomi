# 🚀 LifeHub Dashboard - Complete Tutorial

Welcome to the **LifeHub Dashboard** tutorial series from [CodeWithRomi](https://github.com/theeromi/CodeWithRomi)!

This repository contains a complete step-by-step tutorial for building a beautiful, feature-rich personal dashboard using Flask, Python, and modern web technologies.

## 📺 YouTube Series

Follow along with the complete tutorial series on the CodeWithRomi YouTube channel. This tutorial is broken down into 7 episodes, each building on the previous one.

## ✨ Features

- 🌤️ **Weather Forecast** - Real-time weather data with 7-day forecast
- ✅ **Task Management** - Add, complete, and track tasks with localStorage
- 📅 **Calendar Widget** - Monthly calendar with today highlighted
- 💻 **System Monitoring** - CPU, memory, disk usage, and uptime
- 🌙 **Dark Mode** - Beautiful dark/light theme toggle
- 📱 **Responsive Design** - Works perfectly on desktop, tablet, and mobile
- 📊 **Task Analytics** - Visualize your productivity with charts
- 🔄 **Drag & Drop** - Reorder cards to your preference

## 📚 Tutorial Episodes

1. **Episode 1**: Project Setup & Basic Flask App
2. **Episode 2**: Weather API Integration
3. **Episode 3**: Task Management System
4. **Episode 4**: Calendar Widget
5. **Episode 5**: System Stats & Monitoring
6. **Episode 6**: Dark Mode & Responsive Design
7. **Episode 7**: Advanced Features (News, Network Stats, Drag-and-Drop)

## 🛠️ Tech Stack

- **Backend**: Flask (Python)
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **APIs**: Open-Meteo Weather API
- **Libraries**: Chart.js, SortableJS
- **System Monitoring**: psutil

## 📖 Getting Started

### Prerequisites

- Python 3.7 or higher
- pip (Python package manager)
- A code editor (VS Code recommended)

### Quick Start

1. **Clone this repository**
   ```bash
   git clone https://github.com/theeromi/CodeWithRomi.git
   cd CodeWithRomi
   ```

2. **Navigate to the LifeHub tutorial**
   ```bash
   cd Lifehub  # or the branch/folder where this tutorial is located
   ```

3. **Follow the tutorial script**
   - Open `CodeWithRomi_LifeHub_Tutorial_Script.md`
   - Start with Episode 1
   - Follow along step-by-step

### For Detailed Setup Instructions

See `TUTORIAL_SETUP_GUIDE.md` for:
- Setting up a separate project directory
- Port configuration
- Environment variables
- Deployment tips

## 📁 Project Structure

After completing the tutorial, your project will look like:

```
lifehub-tutorial/
├── app.py                 # Flask application
├── requirements.txt       # Python dependencies
├── templates/
│   └── index.html        # Main HTML template
└── static/
    ├── css/
    │   └── style.css     # Stylesheet
    └── js/
        └── script.js     # JavaScript functionality
```

