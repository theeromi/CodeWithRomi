# 🧠 CodewithRomi – YouTube Tutorial Projects

Welcome to the official GitHub repository for the **CodewithRomi** YouTube channel!

Here you'll find **code samples, project files, and resources** related to each video tutorial, organized by branches.

---

## 📁 Repository Structure

Each video tutorial/project is saved in its own branch with the same name as the video.  
Use the branch dropdown to switch between tutorials.

---

## 🌐 Featured Branches

- `homelab`: Full homelab config pack (Docker Compose, monitoring, security scripts, and sanitized examples).
